# FireWatch — Forest Fire Risk Classification

A Flask-based machine-learning application that estimates forest-fire risk from environmental and fire-weather conditions using the Algerian Forest Fires dataset.

## What changed from the original project

The original application used Ridge Regression to predict the FWI score and exposed the target `Classes` field as an input. This version treats the problem as what it actually is for a fire-event predictor: **binary classification (`fire` vs `not fire`)**.

The target class is not supplied to the model as an input feature.

## ML pipeline

1. Load and clean the Algerian Forest Fires dataset.
2. Convert `Classes` to a binary target: `0 = not fire`, `1 = fire`.
3. Use environmental/fire-weather predictors: Temperature, RH, Ws, Rain, FFMC, DMC, DC, ISI, BUI, and Region.
4. Split data using a stratified 80/20 train-test split.
5. Compare Logistic Regression and Random Forest.
6. Select the model with the better test F1 score.
7. Refit the selected model on the full dataset.
8. Save the model and evaluation metrics under `models/`.

## Evaluation

The application reports Accuracy, Precision, Recall, F1-score, and ROC-AUC. Metrics are generated by `model_training.py` when the model is first trained.

## Run locally

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python model_training.py
python application.py
```

Then open `http://localhost:5000`.

If the dataset is not present locally, the training script downloads the cleaned CSV from the original repository. For a fully offline/reproducible deployment, place `Algerian_forest_fires_cleaned_dataset.csv` in the project root.

## Important limitation

This model estimates fire-event risk from historical Algerian observations. It is a portfolio/educational ML system, not a real-time emergency fire-detection or operational wildfire-warning system.
